# Mitaller Android

Repositorio generado desde la conversión iOS SwiftUI → Android Studio.

Estoy subiendo el proyecto Android aquí porque la descarga del archivo ZIP desde ChatGPT no funcionaba en tu app.

Abre este repositorio en Android Studio usando **File > New > Project from Version Control** con:

```text
https://github.com/Avelascor11/Prueba-pablo.git
```

Si ves archivos `.part` o un script de reconstrucción, sigue las instrucciones dentro del propio archivo.
